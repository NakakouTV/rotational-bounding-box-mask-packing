# パッキング容量の計算

対象は今回の2×1 SVG、2点の凸包、円弧上の字形配置、回転によるスタンプ切り出し方式です。一般のSVG配置に対する絶対最大値を求めたものではありません。

各字形は正方形に収まると仮定し、表示サイズ33px、境界からの余白と他字形までの間隔は最低2pxとしました。実寸で字形の辺をd、表示倍率をsとするとs=33/d、必要な余白m=2/sです。

半径rで角度bの字形中心は (r cos(2b), -r sin(2b))。選択角度aで回転したときの中心は (r cos(2b-a), -r sin(2b-a))。スタンプ範囲の半幅・半高さは0.5 cos(a)、0.5 sin(a)です。回転した字形の正方形外接矩形の半幅・半高さは e=d/2 (|cos(a-b)|+|sin(a-b)|) です。

選択する字形では範囲から字形の外接矩形までの余白を検査します。他の字形では、横か縦のどちらかで完全に範囲外になり、さらにmの間隔があることを検査します。この条件を双方が満たす角度同士をグラフの辺とし、最大クリークを厳密探索しました。

固定半径0.395では角度0.25°刻みで、現在のd=0.055に対して3文字が最大でした。半径0.300～0.495を0.005刻み、角度0.5°刻みで探索した結果は次の通りです。

| 最大テクスチャ上の字形サイズ | 見つかった最大文字数 | 半径 |
| --- | ---: | ---: |
| 約56×56px（現行） | 4 | 0.425 |
| 48×48px | 4 | 0.420 |
| 40×40px | 5 | 0.430 |
| 32×32px | 7 | 0.450 |
| 24×24px | 9 | 0.460 |
| 16×16px | 14 | 0.480 |
| 8×8px | 25 | 0.485 |

各行の表示サイズは33pxです。文字をSVG内で小さくし、スプライトの倍率を増やして表示サイズを維持します。SVGでもScratch内ではテクスチャに変換され、最大辺2048pxという上限があります。2×1 SVGでは最大テクスチャは2048×1024px、倍率1024です。字形サイズを減らすほど最大テクスチャ上の解像度が下がります。16pxや8pxの複雑な漢字の可読性は確認していません。

現行解像度で4文字が入る計算例: 半径0.425、角度25.5°・40.5°・49.5°・65.5°。これは数学的な外接矩形検査による結果です。4文字以上のsb3生成・実行確認はまだです。

表は指定した半径・角度グリッドと正方形字形モデルでの探索結果です。連続角度、文字ごとに異なる半径、実際の輪郭、他の凸包構成を許す場合の最大容量を証明していません。またテクスチャの補間、回転時の描画品質などは実行検証が必要です。

再計算: `python calculate_capacity.py`。数値は`capacity-results.json`に保存されます。
